# 📌 About the Project

**PAIMANA 2.0** is an AI-powered web-based project monitoring and early-warning platform designed to make infrastructure project monitoring more predictive, explainable and action-oriented.

Traditional project monitoring mainly focuses on understanding the current status of a project.

PAIMANA 2.0 adds an intelligent decision-support layer that helps answer:

- What is happening?
- What may go wrong?
- Why is the risk increasing?
- Which factors are contributing to the risk?
- What could happen after a possible intervention?
- What action should be reviewed by the monitoring officer?

The system analyses project cost, expenditure, physical and financial progress, milestones, timelines, dependencies and other relevant project indicators to generate risk insights and early warnings.

The final administrative decision remains with the authorized officer.

---

# 🎯 Problem

Large infrastructure projects are affected by multiple factors such as:

- Cost changes
- Expenditure patterns
- Physical and financial progress
- Delayed milestones
- Procurement issues
- Implementation constraints
- Project dependencies
- Data quality and reporting delays

When these signals are viewed separately, an emerging project risk may not be immediately visible.

The key challenge is therefore not only to **monitor project status**, but also to identify emerging risks early and provide enough context for timely intervention.
